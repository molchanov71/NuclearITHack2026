# Протоколы

## Discovery announce

Поля JSON:

- `nodeId`
- `displayName`
- `protocolVersion`
- `signalBaseUrl`
- `publicKeyFingerprint`
- `capabilities`
- `timestamp`
- `seq`

## Signaling envelope

Поля:

- `type`
- `messageId`
- `sessionId`
- `senderNodeId`
- `targetNodeId`
- `createdAt`
- `signature`
- `payload`
