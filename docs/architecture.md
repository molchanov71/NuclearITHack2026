# Архитектура

Приложение организовано как локальный узел в LAN:

- `security` отвечает за стабильную идентичность узла;
- `discovery` обнаруживает peer-ов через UDP broadcast;
- `signaling` принимает и отправляет управляющие сообщения;
- `session` хранит жизненный цикл соединений;
- `persistence` сохраняет доверие, чат и передачи файлов;
- `ui` отображает состояние узла и диагностику;
- `metrics` аккумулирует события для отладки и демонстрации.

Фундаментальный блок ТЗ покрыт базовым каркасом и готов к дальнейшему развитию WebRTC-логики.
